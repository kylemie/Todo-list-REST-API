Todo REST API

REST API для управления задачами (todo list), написанная на Go с использованием gorilla/mux

📋 Возможности

- ✅ Создание новых задач
- 🔍 Получение задачи по названию
- 📄 Получение всех задач
- ⏳ Получение только незавершенных задач
- ✅ Отметка задачи как выполненной/невыполненной
- ❌ Удаление задач

🛠 Технологии

- Go 1.25.3
- Gorilla Mux (роутинг)
- Стандартная библиотека HTTP

🏃‍♂️ Запуск проекта

Предварительные требования
- Установленный Go 1.25.3 или выше

Установка
```bash
# Клонирование репозитория
git clone <repository-url>
cd rest-api

# Установка зависимостей
go mod download
```

Запуск сервера
```bash
go run main.go
```

Сервер запустится на порту `9091`.

📡 API Endpoints

Создание задачи
```
POST /tasks
Content-Type: application/json

{
    "Title": "Название задачи",
    "Description": "Описание задачи"
}
```

Получить задачу по названию
```
GET /tasks/{title}
```

Получить все задачи
```
GET /tasks
```

Получить незавершенные задачи
```
GET /tasks?completed=true
```
Изменить статус задачи
```
PATCH /tasks/{title}
Content-Type: application/json

{
    "Complete": true/false
}
```
Удалить задачу
```
DELETE /tasks/{title}
```

📁 Структура проекта

```
rest-api/
├── main.go             # Точка входа
├── go.mod              # Модуль и зависимости
├── http/               # HTTP слой
│   ├── handlers.go     # Обработчики запросов
│   ├── server.go       # HTTP сервер
│   └── dto.go          # Data Transfer Objects
└── todo/               # Бизнес-логика
    ├── task.go         # Модель задачи
    ├── list.go         # Управление списком задач
    └── errors.go       # Ошибки домена
```

🔧 Особенности реализации

- Потокобезопасность с использованием `sync.RWMutex`
- Валидация входных данных
- Детальные сообщения об ошибках с временными метками
- JSON формат для всех запросов и ответов
- Соответствие HTTP статус-кодам
